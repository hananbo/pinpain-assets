# PinPain male anatomy assets

Male body for the PinPain harness, served to the web UI via jsDelivr.

Source: `ashemag/human-atlas` (MIT-licensed packaging) at commit `1c38bf35c254a891200d3cedecfd57abebe83d8d`,
which repackages **BodyParts3D/Anatomography** by DBCLS, Japan - © The Integrated Database Project,
licensed **CC BY-SA 2.1 JP** (https://creativecommons.org/licenses/by-sa/2.1/jp/).
2,234 named structures; chunked binary meshes with per-structure offsets in `atlas.json`.

Anatomical data is for orientation and communication with care providers - not a diagnostic tool.
